Open the step-by-step guide

Install Git, copy the project

Install Git and reopen VS Code. Then Terminal → New Terminal: a panel where you type commands instead of clicking. Run these one at a time (Enter after each):

mkdir C:\sites
cd C:\sites
git clone https://github.com/avisalmon/FullStackBKM.git my-site
code my-site

A new window opens on your copy: click Yes, I trust the authors. (If code isn’t found, use File → Open Folder.)

Open the AI chat and type

In the new window: Copilot in Agent mode, or the Claude Code panel. Then say:

Tell me what to do

Come back any day and say it again: it resumes where you stopped.

How you know you did it right

Your assistant runs a read-only checker after every phase and walks you through the result: your repository, your local site and your live site, with exactly what to fix. You can run it too:

python scripts/verify_site.py
python scripts/verify_site.py --url http://127.0.0.1:8000
python scripts/verify_site.py --url https://your-site.onrender.com

Each line is a pass, a warning (worth a look) or a fail (fix first), with a hint.

You have graduated when

  • the checker shows no FAIL
  • your tests pass
  • you have practised one restore
  • you can explain, in your own words, what your data model is and why its main relationship exists

Questions

Do I need to install Python myself?

No. You install Git, VS Code and an AI engine. The chat checks your computer and installs Python and GitHub’s command-line tool itself (without admin rights where possible), and fixes problems it finds.

Do I need to know how to code?

No. You need to know what you want and be willing to answer questions. You will pick up the vocabulary as you go, and the tutorial makes it faster.

Which AI assistants work?

Claude Code and GitHub Copilot (in Agent mode, which lets it run commands and edit files). The playbooks (step-by-step instructions the AI follows) ship twice, in .claude/skills/ and .github/skills/, and are kept identical by a script and a test. AGENTS.md serves other tools.

What if something breaks?

The assistant reads the deploy logs first, as the playbook requires, then makes one targeted fix. There is a rollback guide, a backup and restore guide, and a list of 30 traps that already bit a real production site.

Is my code and data private?

Your site repo is created private. Secrets live in a git-ignored file and in Render, never in the code, and the repo scans every commit for keys. Only this blueprint is public.

Can I disagree with the privacy advice?

Yes. It is advice, not a gate. Your assistant explains why it recommends something and how serious it thinks it is; if you choose differently it records your decision and reason and helps you do it as safely as possible. It is not legal advice, and for children’s data you should talk to a lawyer.

Can I use a different host or database?

The blueprint is built for Render and SQLite on a persistent disk, which keeps it simple and cheap. Moving to Postgres or another host is possible later and is on the roadmap.

Words you’ll meet

Plain meanings, so nothing on the way sounds like a secret code. Your assistant uses the same words, and you can always ask it “what does that mean?”.

GitHub
a website that stores code. Your site's code will live there, privately.
Repository (“repo”)
one project's folder on GitHub, with the full history of every change.
Git
the program on your computer that copies projects from GitHub and records every change you make.
Clone
make a copy of a repository on your own computer.
VS Code
the editor: the program where you see your project's files and talk to the AI.
Extension
an add-on you install inside VS Code, like GitHub Copilot or Claude Code.
Agent mode
the Copilot setting that lets the chat do things (run commands, edit files), not just answer.
Terminal
a panel where you type commands instead of clicking. In VS Code: Terminal → New Terminal.
Command
one typed instruction. You run it by pressing Enter, then wait until the terminal is ready again.
Two-factor sign-in (2FA)
signing in needs your password and a one-time code from your phone, so a stolen password alone is not enough.
Python
the programming language your site is written in. The chat installs it for you.
GitHub command-line tool (“GitHub CLI”)
a small program that lets the chat talk to GitHub for you, for example to create your private repository. The chat installs it; you log in once in the browser.
Private vs public
private: only you can see it. Your site's code is private. This blueprint is public so anyone can start from it.
Render
the hosting company whose computers run your site on the internet, about $7.25 a month.
Blueprint (on Render)
Render's one-click setup: it reads a settings file in your project and creates everything your site needs.
Deploy, go live
put the latest version of your site on the internet. Here it happens when you say so.
Logs
the server's diary of what happened. When something fails, the chat reads them before changing anything.
Domain
your own address, like your-name.com, rented yearly from a domain shop (a “registrar”).
DNS records
a few settings at the domain shop that point your address at Render. You copy them from Render.
HTTPS, the padlock
the encrypted connection that shows a padlock in the browser. Render sets it up for you.
Secret, key
a password your site uses to talk to a service (Render, Google, OpenAI). It goes in a private file or in Render's settings, never in the chat.
Google sign-in key (“OAuth client”)
what you create in Google's console so your site can offer “Continue with Google”.
Bucket
a storage space in Google Cloud. Your offsite backup copies go there.
Data model
the plan of what your site remembers and how those things connect. You approve it before anything is built.
Playbooks (“skills”)
step-by-step instructions inside this project that the AI follows, so it builds your site the same careful way every time.
