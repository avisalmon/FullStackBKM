FullStackBKM

A blueprint for building a real full-stack website, Django on Render, by working with Claude.

Start

  1. Install Python 3.12, Git, the GitHub CLI, and Claude Code (signed in).
  2. Use this repo as a private template for your site, and clone your copy.
  3. Open the folder in Claude Code and say:

“Help me build my full stack site”

Claude interviews you, sets everything up, deploys it, and does all it can on its own. When it needs you (an account, a card, a consent screen, a DNS record) it tells you exactly what to click.

What you will learn

Claude mentors you as it builds: how a Django site works, then the lesson that matters most, data models and relationships (what they are and why they decide whether a site is easy or painful to grow), plus a practical design guide and privacy advice (HTTPS, cookies, young users, consent; advice, not rules: you decide). A checker, scripts/verify_site.py, tells you whether you did it right.
